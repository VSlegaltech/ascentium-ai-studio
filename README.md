# Ascentium AI Studio prototypes

Static site, no build step:
- `/` landing page
- `/incorporation/` Incorporation prototype
- `/ip/` Global IP prototype

## Deploy to Vercel
**CLI:** install Node.js, run `npm i -g vercel`, then in this folder run `vercel --prod`.
**GitHub:** push this folder to a repo, then in Vercel choose Add New > Project, import it, set Framework to "Other" with no build command and the root as output, and deploy.

Concept prototypes: AI steps are simulated; IP pricing uses Ascentium's SGD sheet and WIPO fees (indicative).
